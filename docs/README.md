# APRE10 Calculator (web)

Static, no-server version of the Impulse PT APRE10 calculator. Everything is in `index.html`.

- Live: https://alexpeters-impulse.github.io/apre/
- WordPress: paste `wordpress-embed.html` into a Custom HTML block (or Elementor HTML widget). The frame auto-resizes.
- Protocol settings (tiers and percentages) are the `TIERS` array near the top of the script.
- Patient history is saved in the browser's localStorage only. No data leaves the device.
